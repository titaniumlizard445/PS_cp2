# Geometry Calculator
***
The Geometry Calculator is a Calculator that can calculate the area of almost any 2D shape and has a limited variety of 3D shapes that can be calculated. There are a few actions that can be made in each menu, the most notable being:
1. Create new shape, which allows for the user to create a new shape to their liking.
2. View shape, shows all created shapes and their stats
3. Compare shapes, allows user to choose two shapes by their names and then compare two pre-set stats about them.
***
## To run the project
1. Open the main.py file
2. hit the triangle or run button
***

No libraries required
