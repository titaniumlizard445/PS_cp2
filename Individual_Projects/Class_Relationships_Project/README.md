# Video Game Character Creator
This program Allows users to Create and manage a Video Game Character's:
- **Abilities**
- **Stats**
- **Inventory**
- **Armor**
- **Weapons**
- **Class**
***
## How To Use The Program
1. Open up the src folder
2. Open main.py
3. Click the Triangle at the top right of your screen or the "run" button
